# APP 真机验证清单（Device Test Checklist）

适用版本：v0.7.0 及以后 · 配套固件：ESP32S3（MQTT 云链路 + BLE/TCP 透传桥）/ GD32H7
执行前提：已安装 debug 或 release APK；设备端固件已烧录并连接云端；现场蓝牙模块（BT24/HC05）就绪。

---

## 0. 环境与权限

- [ ] 安装后首次启动弹出通知权限（Android 13+），允许/拒绝两种路径各验证一次
- [ ] 首次进入 BLE/透传页按需弹出蓝牙扫描/连接权限（Android 12+）；Android 11 及以下弹定位权限
- [ ] 拒绝权限时页面有明确提示且不崩溃；授权后功能可用

## 1. 云链路（MQTT）

- [ ] 设置页连接 Broker（默认 `tcp://broker.emqx.io:1883`），状态显示"已连接"
- [ ] 监控页收到 sensors 数据（温/湿/气/CO₂/气压实时刷新）
- [ ] 在线判定：停止设备心跳 ≥60s 后显示"设备离线"；恢复心跳后变"设备在线"
- [ ] 控制页下发 LED 开/关：设备执行 + 命令历史出现"已确认"+ "回执[led] 设备已执行"
- [ ] 状态查询：命令历史出现回执；监控页心跳刷新
- [ ] 远程重启：设备重启后 30s 内自动重连成功（自愈重连生效）
- [ ] 断网演练：断开 Wi-Fi/拔网线 30s 再恢复 → 自动重连（退避 2s/4s/…/60s），无需手动操作
- [ ] 后台保活：设置页开启"后台保活"→ 锁屏 10 分钟 → 通知栏常驻状态正确，解锁后连接未断
- [ ] 强制杀掉 APP → 从最近任务移除 → 保活服务重启（START_STICKY）并自动恢复连接
- [ ] 调试面板：对 `ind_edge/terminal/cmd` 发布 `{"cmd":"status"}` 有回执；订阅任意主题可收消息

## 2. OTA（契约 6.1 闭环）

- [ ] 控制页输入有效固件 URL → 下发 → tvOtaState 依次显示：下载中(带进度百分比) → 校验并切换 → 升级完成
- [ ] 下载中断网 → 状态显示失败（detail），设备可正常回滚运行
- [ ] 升级后设备重启并上报新版本；监控页"设备版本"更新（若该字段已展示）

## 3. BLE 透传（需 ESP32 GATT Server 固件）

- [ ] BLE 页扫描到 `ind_edge_esp32s3`，RSSI 数值合理且列表按信号降序
- [ ] 点击连接：状态"已连接"→"透传通道就绪"；日志区无异常
- [ ] MTU：设备日志确认协商 185（ESP 端 log "BLE MTU negotiated"）
- [ ] 透传回环：发送 ASCII/HEX → 设备→GD32 链路→回程数据在接收区显示（时间戳+计数增长）
- [ ] 长数据（>MTU）分片发送不丢字节；HEX 格式错误输入有提示
- [ ] 断开设备电源 → APP 状态回到"已断开"；RSSI 曲线停止刷新

## 4. 经典蓝牙 SPP（GD32 BT24/HC05）

- [ ] 未配对设备点击 → 提示先配对；系统配对后再次点击可连接
- [ ] 已配对设备列表出现"已连接"标记；断开后标记消失
- [ ] 9600bps 透传：发送内容设备侧可见；设备侧发送 APP 可收
- [ ] 拔掉蓝牙模块电源 → 状态转"重连中"，恢复供电后自动连接成功
- [ ] 点击其他设备自动切换目标（旧链路断开、新链路建立）

## 5. LAN TCP 透传（需 ESP32 TCP Server 固件）

- [ ] 设置页/透传页配置 `ESP32_IP:8080`，连接成功
- [ ] mDNS 环境（可选）：`ind_edge.local` 可解析
- [ ] 双向透传收发正常（时间戳/计数）；服务端重启后 APP 自动重连
- [ ] 连接中点击"连接"提示忙；已连接点击变"断开"

## 6. UI / 体验

- [ ] 深色模式：系统切换深色 → 图表网格/日志底色/文字对比度正常
- [ ] 启动画面：冷启动无白屏闪烁，过渡到主界面
- [ ] 五页切换：监控曲线/日志/告警历史/命令历史切页返回后**不丢失**
- [ ] 横竖屏旋转（如未锁定）：不崩溃，状态恢复
- [ ] 关于页：版本/构建时间/SDK/契约版本显示正确（设置页-关于）

## 7. 数据与导出

- [ ] 传感器数据持续落盘（连接 10 分钟后"查询历史"有记录）
- [ ] "24h 统计"显示按小时聚合（均温/均湿/气体峰值）
- [ ] 导出 CSV：生成文件并唤起分享（文件管理器打开内容正确，中文列头正常）
- [ ] 清空历史后查询为空；曲线清空
- [ ] 30 天清理策略（可改系统时间模拟或查库确认旧记录被删）

## 8. 告警

- [ ] 触发等级 ≥2 告警 → 通知栏弹出（标题含告警号、正文含等级/值）
- [ ] 关闭"推送告警通知"→ 不再弹通知
- [ ] 勿扰时段（如 22:00–07:00，含跨零点）：时段内不弹；时段外正常
- [ ] 告警历史置顶显示与一键清空正常

## 9. 配置管理

- [ ] 修改 Broker/Client ID/BLE UUID/TCP 地址 → 保存 → 杀进程重启后配置保留
- [ ] 导出配置 JSON → 修改参数 → 导入备份 → 参数恢复；连接中导入提示需重连
- [ ] 非法 JSON 导入提示格式错误且不破坏现有配置

## 10. 稳定性（建议 ≥2 小时）

- [ ] 双链路（MQTT+BLE/TCP）并发 2 小时：无崩溃、无 ANR、内存无持续增长（`adb shell dumpsys meminfo`）
- [ ] 弱网/断网反复 10 次：每次均在 60s 内自愈
- [ ] 日志观察：无 `E/AndroidRuntime`、无 `SecurityException`
